# Where the pictures come from

`find` at 32 and 16 px is copied unchanged from the Windows 95 shell's icon
set (chicago-desktop/shell, `assets/icons/SOURCE.md`): Microsoft's artwork
from `shell32.dll`, extracted to RGBA PNG. It is Microsoft's artwork, not part
of this module under MIT; the file name is the picture's name in the pack,
`chicago.antibug:images/find`.
